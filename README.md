# Shukin PRO — Sell Grid (Bybit Short) 24/7

Python-версия страницы `index.html` (Sell Grid — Short, режим Щукина). Работает на Railway круглосуточно,
браузер держать открытым не нужно. Страница состояния — по адресу сервиса (обновляется каждые 10 с).

**Логика как на странице:** сетка SELL-лимиток выше цены, тейк/стоп от средней цены входа, мейкер-тейк,
режим Щукина (шаг ≥1%, тейк ≥0.7%, аварийный стоп 10%, добор выше в открытый шорт, фильтр OI + CVD),
защита от спайка, фильтр ATR, дневной лимит убытка, сканер «пампы под шорт» / «ультра-волатильные 1m».

**Отличие:** бот трогает только свои монеты (где сам ставил ордера `sg_`). Позиции других ботов на счёте
не закрывает и сетку на их монеты не ставит. `MANAGE_ALL=1` — как на странице, все позиции счёта.

## Переменные Railway

| Переменная | По умолчанию | Что |
|---|---|---|
| `BYBIT_API_KEY`, `BYBIT_API_SECRET` | — | ключи Bybit (Contract trade) |
| `LIVE` | `0` | `1` — реальные ордера; `0` — симуляция, только лог |
| `TESTNET` | `0` | учебный счёт |
| `SHUKIN` | `1` | режим Щукина |
| `SYMBOL` | пусто | своя монета; пусто — выбирает сканер |
| `SCAN_MODE` | `pump` | `pump` / `ultra` / `off` |
| `SCAN_EVERY_MIN` | `5` | как часто пересканировать |
| `SIZING` | `auto` | `auto` — размер от депозита; `fixed` — `ORDER_USDT` на уровень |
| `DEPOSIT_PCT` | `90` | какую часть свободного баланса задействовать, % |
| `LEVERAGE` | `3` | плечо на монетах бота |
| `MAX_ACTIVE` | `10` | максимум монет одновременно (реально — сколько позволяет депозит) |
| `MIN_LEVEL_USDT` | `6` | минимальный уровень сетки, $ |
| `INTERVAL` | `5` | таймфрейм свечей, мин |
| `GRID_STEP_PCT`, `GRID_LEVELS` | `1` / `5` (Щукин) | шаг и число уровней |
| `TP_PCT`, `SL_PCT` | `0.7` / `10` (Щукин) | тейк и стоп, % |
| `ORDER_USDT` | `12` (Щукин) | размер уровня при `SIZING=fixed`, USDT |
| `MAX_DAILY_LOSS` | `15` | дневной лимит убытка, $ |
| `CYCLE_SEC` | `3` | интервал цикла, с |
| `MAKER_EXIT`, `SPIKE_PROTECT`, `VOL_FILTER`, `SHUKIN_FILTER` | `1` | мейкер-тейк, защита от спайка, фильтр ATR, фильтр OI/CVD (фильтры можно вкл/выкл кнопками на странице — выбор сохраняется на диске и важнее переменных) |
| `MAX_SPIKE_PCT`, `MIN_ATR_PCT`, `MAX_ATR_PCT` | `0.5` / `0.2` / `5` | пороги |
| `CONTROL_KEY` | — | пароль для кнопок Старт/Стоп |
| `START_PAUSED` | `0` | `1` — после перезапуска ждать «Старт» |
